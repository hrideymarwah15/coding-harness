# Skill: Repository Exploration

## Goal
Build enough repository understanding to act without reading the entire codebase.

## Procedure
1. Check Git status.
2. Identify runtime/package manager.
3. Read root instructions.
4. List top-level directories.
5. Inspect package/build/test manifests.
6. Search for task-specific identifiers.
7. Inspect relevant symbols and callers.
8. Identify tests.
9. Produce a compact repository hypothesis.

## Output
- relevant files
- relevant symbols
- architecture hypothesis
- commands
- uncertainty
